# Анализ и подготовка временных рядов для прогнозирования расходов

## О проекте

Проект посвящён подготовке данных для прогнозирования операционных расходов (OPEX) и последующей оценке точности полученных прогнозов.

Основная задача — сформировать набор временных рядов, пригодных для прогнозирования, с учётом полноты исторических данных и актуальности расходов в текущем году.

Проект состоит из двух частей:

1. **Подготовка временных рядов** — восстановление пропущенных наблюдений, отбор актуальных рядов и обработка отклонений.
2. **Оценка точности прогнозов** — сравнение результатов внешней модели прогнозирования с фактическими и плановыми значениями.

Модель прогнозирования разрабатывалась отдельно и в данный репозиторий не входит.

## 1. Подготовка временных рядов

**Файл:** `frcst_OPEX-Copy2.ipynb`

Алгоритм обрабатывает временные ряды расходов, сформированные по комбинации поставщика, драйвера и услуги.

### Основные этапы

**1. Восстановление пропущенных наблюдений**

Если в предыдущем году отсутствует фактическое значение за определённый месяц, оно заменяется плановым значением аналогичного месяца текущего года.

Восстановленные значения включаются в итоговый набор данных для прогнозирования.

**2. Проверка актуальности расходов**

В дальнейшую обработку допускаются только временные ряды, имеющие минимум одно фактическое наблюдение в текущем году.

Это позволяет исключить расходы, которые присутствовали в истории, но не наблюдаются в текущем периоде.

**3. Проверка достаточности истории**

После восстановления пропусков отбираются ряды, содержащие не менее 36 наблюдений за рассматриваемые периоды.

**4. Обработка отклонений**

Для временных рядов рассчитываются темпы роста, коэффициент вариации и границы допустимых отклонений.

При выполнении условий алгоритма отдельные значения корректируются с использованием средних значений.

**5. Формирование итогового набора данных**

Подготавливаются обработанные временные ряды для передачи в модель прогнозирования.

## 2. Оценка точности прогнозов

**Файл:** `Для проверки прогноза.ipynb`

Вторая часть проекта предназначена для анализа результатов прогнозирования.

Основные операции:

- Объединение фактических, плановых и прогнозных значений.
- Расчёт процентных отклонений.
- Категоризация отклонений.
- Определение доли наблюдений с отклонением менее 25%.
- Формирование итоговой таблицы для анализа качества прогнозов.

## Демонстрационные данные

Для проверки алгоритма подготовки временных рядов используются синтетические данные, не содержащие реальной банковской информации.

На тестовом примере продемонстрированы:

- Восстановление трёх пропущенных наблюдений за 2025 год.
- Отбор ряда с тремя фактическими наблюдениями за 2026 год.
- Проверка минимального порога в 36 наблюдений.
- Формирование временного ряда из 39 наблюдений.

## Ограничения

Заполнение пропусков плановыми значениями может влиять на статистические характеристики временного ряда. Метод применяется как бизнес-правило подготовки данных и не гарантирует прогнозируемость каждого отобранного ряда.

Исходная модель прогнозирования не включена в проект. Второй ноутбук предназначен исключительно для оценки результатов её работы.
